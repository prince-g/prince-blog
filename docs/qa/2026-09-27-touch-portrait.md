## 交付内容

- 键盘 → 磁轴的原有装配与正反向渐变保留。
- 磁轴阶段的新按键或非拖动点击，从两指中央触点展开进入人物首页。
  转场约 1.65 秒，包含聚光、不规则竖向开口、边缘白色细线与颗粒。
  灵感来自用户提供的 Shopify 录屏；没有复制或嵌入 Shopify 站点素材。
- 保留拖动观察、返回键盘、暂停自转。Tab、快捷键、输入法、长按重复与控件操作不会误触跳页。
- 人物首页使用用户原视频、首帧和指定背景。桌面左文右人，手机上下布局，避免文字遮住脸。
- 首次未移动鼠标时播放完整开场；实际鼠标移动后映射到现有视线姿态。
  当前使用一个隐藏视频解码器与一个不透明 canvas，沿源视频时间连续追踪，完整解码后替换画面。
- 首次向下滚动或点击向下探索，先沿现有动作回归首帧，确认该帧呈现后再滚到栏目入口。
  离开首屏后不再跟随；返回顶部可再次跟随。磁轴场景在切换完成后卸载。
- 毛玻璃导航、手机菜单、桌面展开菜单、重新体验、现有 Work / Notes / About 路由入口。
- 无 WebGL 或模型错误时允许继续主页。视频失败保留首帧；定位停滞有超时恢复。
  隐藏标签页清理待执行的视频定位与回正操作；减少动态偏好使用简短淡入与静态首帧。

## 素材与边界

- 视频来源、优化参数、姿态时间详见 `public/media/portrait/README.md`。
- Manrope 字体来自 Google Fonts 官方仓库，SIL OFL 许可证随文件保留在 `public/fonts/manrope/OFL.txt`。
- 原素材是二维视频：能选择已有姿态与相邻过渡，不能生成任意新头部角度，也不能独立改变眼球与表情。
- 当前使用避开人物的排版，没有制作动态人物抠像；若以后要大标题穿过人物轮廓，需要透明视频或逐帧前景遮罩。
- 主页名称沿用项目 Prince Blog；简介为可替换草稿。后续区承接现有栏目，具体作品与文章仍使用原有占位页。
