# 人物重影与转向流畅度修复

工作目录：`E:/project/front/prince-blog`。分支 `main`，基线 `75db1d1`。
修改保留在当前工作区，未提交、未推送；原视频和旧媒体资产均保留。

## 原因和修复

- 旧版是视频定位配合两层淡入淡出，不是抽取少量图片制作幻灯片。两层视频同时半透明时，底部常驻首帧又透出，形成三张脸的叠影。
- 旧版每次定位之后锁定 180ms，理论上限约 5.56 次更新/秒。现改为单个隐藏 video 解码、单个不透明 canvas 呈现；解码期间保留上一完整画面，seeked 后原子替换，没有淡化锁定。
- 同时仅保留一次视频定位；鼠标的新目标持续覆盖目标时间，按显示帧进行阻尼推进。解决中心边界抖动及下方到右方的时间硬切。
- 原素材虽标为 60fps，实际约 24fps 独立画面。新运行媒体 `portrait-motion-60.mp4` 经运动补偿插帧生成 60fps，1280×720、599 个全关键帧、19,253,199 bytes。更快定位以额外媒体体积为代价。
- 回正回调在首帧真正呈现后执行。定位超时、媒体失败、半帧浮点边界以及旧 play() 拒绝回调都已有回归测试。

## 素材边界

二维原视频没有录制任意两方向间的直接动作。当前通过视频已有动作连续衔接，缺少的下方到右方路径经过回正姿态；不会生成全新头部角度。
8.4s 与 0s 的正面神态接近，但不是像素相同，环形接缝仍可能有轻微差别。光流补帧也不等于新增真实拍摄细节，头发和贴纸细字略软。
此次验证没有承诺弱网加载速度或所有设备恒定 60fps；预览素材无需重新生成即可复测。
