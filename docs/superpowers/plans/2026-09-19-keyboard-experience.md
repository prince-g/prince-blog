# 纯白键盘进入体验

按用户提供的三视图、加载截图和两段本地视频扩展已有场景，不增加依赖，不替换白金模型。

1. 页面只保留白色背景、三维毛玻璃输入框与右下角三角入口；背景替换留 TODO。准备状态的相机 yaw/roll 为 0，使用正向俯视，拖动保留自由旋转。
2. 数字加载层订阅真实模型/贴图资源完成情况，最多 99；场景准备完成才显示 100。加载失败保留重试，无 WebGL 保留静态降级。
3. 同一 Canvas 使用 loading → assembling → ready → exiting → switch 状态。装配使用 JSON 的展开/闭合位置；淡入爆炸图后合拢，完成前禁用输入和入口。
4. 输入框使用与 WebGL 相机一致的 CSS 三维投影，固定在键盘上方，保留原生编辑与中文输入能力。
5. 入口按钮不要求文本；键盘 Enter 要求 trim 后非空，中文输入组合期间不能误跳转，重复 Enter 不重复启动。
6. 转场遵循视频：键帽消退、轴群错峰飞出、保留 KeyJ 轴，机壳退场、镜头聚焦。磁轴展示支持拖动旋转、按压和返回；复用加载资产。声音继续 TODO。
7. 减少动态效果偏好下短暂淡入直达终态。通过状态/时间线/投影/按键单测、构建与桌面和手机实际浏览器验收。

文件分工：模型子任务负责 KeyboardModel / KeycapMesh / SwitchInstances / FocusedSwitch；加载子任务负责 asset-progress 与资源加载接入；主任务负责页面、相机、三维输入框、状态衔接与验收。
